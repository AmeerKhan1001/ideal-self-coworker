# Workspace

The Workspace is the coworker's workbench. It is not the durable Human Model.

It contains:

- `evaluations/` — the quality bar used to test behavior and candidate model changes.
- `episodes/` — meaningful experiences/corrections/outcomes from real work.
- `learning/` — candidate-change and keep/revert process.
- `artifacts/` — intermediate work with no better natural home.
- `outputs/` — final human-facing results with no better natural home.

Inputs and outputs should remain in their authoritative external systems when that is more appropriate.
