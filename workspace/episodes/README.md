# Episodes

Episodes are compact records of meaningful work experiences.

Do not record everything. Create an episode when there is useful evidence for future improvement, such as:

- a human correction,
- an unexpected failure,
- a surprising success,
- an important real-world outcome,
- a repeated friction point,
- a new durable fact discovered through work.

Episodes are evidence, not automatically permanent knowledge. Extract durable learnings through the learning protocol.

Use `TEMPLATE.md`.
