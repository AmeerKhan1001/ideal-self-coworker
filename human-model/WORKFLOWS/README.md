# Workflows

Workflows encode repeatable ways of producing recurring outcomes.

A workflow contains stable process knowledge. The generated artifacts for a particular run do not belong in the workflow definition.

Examples across domains:

- Work: feature development, bug solving, investigation, PR review, deployment.
- Personal: daily brief, travel planning, financial decision support.
- Business: customer interview, opportunity assessment, experiment, proposal, delivery.

Create a workflow only when the process is recurring enough to benefit from an explicit contract.

Use `TEMPLATE.md` as the starting point.
