# Human Model

The Human Model is the durable, interpretable representation of the human standard the coworker should operate from.

It is not a complete copy of a person. Store only information that materially changes future reasoning or execution.

## Contents

- `CONTEXT.md` — durable reality the coworker needs to know.
- `PRINCIPLES.md` — human-owned definition of “better.”
- `OPERATING_SPEC.md` — expected behavior, judgment, communication, prioritization, and authority boundaries.
- `WORKFLOWS/` — recurring ways of producing outcomes.
- `HISTORY.md` — past events/decisions that explain the present.
- `LEARNINGS.md` — reusable lessons that should affect future behavior.

## Rule

If something is primarily about a specific current run, task, ticket, decision, experiment, or output, it probably belongs in `workspace/` or its authoritative external system instead.
